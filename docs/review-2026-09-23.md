## How to work (read once, applies to every phase)

- **Use the dedicated tools.** Read files with Read, search with Grep, change files with
  Edit/Write. Never shell `cat`/`head`/`grep`: a global RTK hook rewrites them and truncates or
  "filters" output. For a multi-file change, Write a `.mjs` script to the scratchpad and run
  `node <file>`. Commit messages: Write to a file, then `git commit -F <file>`.
- **Never trust `npm run lint` in a Claude session.** The hook rewrites it to an ESLint wrapper
  that fails on oxlint's output. Until Phase 0 lands, run `node_modules/.bin/oxlint src` and read
  its exit code. After Phase 0, run `node scripts/verify.mjs` and nothing else.
- **Commit per item group, cut a version per phase.** Push only when the owner says "push"
  (a push deploys).
- Browser checks: the pane throttles timers when hidden, first screenshots time out (retry once),
  and old HMR errors stay in the console buffer — trust a fresh reload.

## Phase 2 — The report hand-off to NW Publisher → **0.26.0**

The single biggest usability win. Goal: on the 1st–10th of a month, open Meleo, see "September
report ready", tap copy on each figure, paste into NW Publisher, tap "Mark submitted".

1. **`src/monthReport.ts` (new, pure, tested)** — `buildMonthReport(logs, calls, people, prefs, aux, participatedMap, year, month)` →
   `{ participated, bibleStudies, bibleStudyNames, hours (whole), carriedMin, creditMin, creditNote, showHours }`.
   - `participated` = ticked **or** any time logged **or** any call logged that month.
   - `bibleStudies` = contacts with status `bible-study` **and a call in that month** (fixes past
     months showing today's count), with names listed.
   - `showHours` from a new `roleReportsHours()` in `schedulePrefsRole.ts` (pioneer, or an aux
     month). A publisher's personal goal is **not** a reason to report hours.
   - `creditNote` = e.g. "Credit: 5h – LDC" for the comments box.
2. **`Reports.tsx`** (rename tab label to **Report**):
   - Top card = the hand-off, same order as NW Publisher: Shared (Yes/No toggle, writes
     participation), Bible studies (names listed small), Hours (whole; "30m carries forward"),
     Comments (credit line). **A copy button on each value.**
   - **Mark as submitted** → new key `fieldservice_reported_months` (owner `settings.ts`; add to
     CLAUDE.md key table; *not* blocklisted — it is a record).
   - Default to the **previous** month on days 1–10 until that month is marked submitted.
   - Replace the email field with **Share report** (OS share sheet; body = the same lines).
     Enable Share/Copy whenever `participated || bibleStudies > 0` (today they are disabled at 0h).
   - Delete `↺ Re-run` and the 600 ms "Gathering…" delay. Hide the hours encouragement card when
     hours aren't tracked. "doors not answered" → "homes called on".
3. **Service tab banner** on days 1–10 until marked: "September report ready →" (links to Report).
4. Merge the two participation cards on Service (progress card text + `MonthlyParticipationBox`)
   into one row with the checkbox. Copy: "Tap when you've shared this month" (no "not yet").
